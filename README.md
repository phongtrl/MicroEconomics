# MicroEconomics

*Mikroøkonomi – Kunsten å ta bedre beslutninger* er en norsk lydbok på 27 minutter med 12 kapitler, regneeksempler og beslutningscase for MBA-nivå.

- Åpne `index.html` for å lytte, bytte kapittel og lese manuset. Spilleren husker lytteposisjonen når nettleseren tillater lokal lagring.
- Åpne [hele lydboken](audio/Mikrookonomi.m4b) i en lydbokspiller for avspilling med kapittelinndeling. De enkelte kapitlene ligger som MP3-filer i `audio/`.
- Manuset ligger i `chapters.js`. Lydsporene er lest inn med den norske [Piper-stemmen talesyntese](https://huggingface.co/rhasspy/piper-voices/tree/main/no/no_NO/talesyntese/medium).
